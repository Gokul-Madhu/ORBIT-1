Starting WebGL

Scripted electronics test mission with an independent 400 km orbital reference. Vehicle geometry and pre-orbit motion are illustrative.

Quick start
  1. Explore. Drag to orbit, scroll or pinch to zoom. Select a labeled module in the cutaway or use the component buttons. Toggle the shell or move Explode to expose the racks.
  2. Run. Press Run / resume to advance the mission. Pause and use Step 250 ms to inspect one sensor sample and its packets.
  3. Try a fault. Choose Primary sensor interruption, press Inject, then step while paused. Fault focus opens the red IMU. Use Bus network to trace the failed SPI route. Recover selected fault and step again.
  4. Review. Review recording opens a timeline you can scrub or play. Return to live restores the mission controls.
